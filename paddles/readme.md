# 概要

「paddles」は、 ブロック崩しとシューティングを組み合わせたゲームです。

A/Dまたは左右の矢印キーでパドルを操作し、 ボールを打ち返して各ステージを攻略します。

黒背景に白色のパドルとブロック、ボールといったシンプルな図形で構成されます。

## ステージ

各ステージのデータは、 次のような形式を想定します:
```jsonc
{
    // ステージ番号
    "identifier": 1,

    // ステージ名
    "name": "breakout",

    // 13x5のマップ
    "map": [
        "             ",
        " ########### ",
        " ########### ",
        " ########### ",
        "             "
    ],

    // 出現する敵
    "enemies": [], // ステージ1では出現しない

    // 出現インターバル (秒単位)
    "spawn_interval": null, // ステージ1では出現しない

    // 最大出現数
    "spawn_limit": 0
}
```

## エネミー

各エネミーのデータは、 次のような形式を想定します:
```jsonc
{
    // 敵の名前
    "name": "triangle", // マップの "enemies" で使用

    // 攻撃手段
    "bullet_type": "self_destruction", // 自分自身に被弾判定を持ち、ヒット時に消滅

    // 移動手段
    "movement_type": "fall", // 出現した位置からそのまままっすぐ降下していく

    // HP
    "health": 1, // ボールヒットごとに敵の大きさが縮小 (縮小時に1回だけパルスアニメーション) し、 healthが0になると消滅、 赤色ボールヒットであればhealthを即座に0にする。

    // ダメージ量
    "damage": 2 // パドルに与えるダメージ量
}
```

### ヒットボックス関連の補足

パドルは、ボールを受け止める判定は自身の見た目よりわずかに広く持ちますが、 敵弾がヒットする判定は見た目通りになります。

また、 敵弾のヒット判定はどの攻撃も1pxしか持ちません。

## パドル

パドルはHPを持ちます。 HPについて具体的な数値はゲーム内で表示されませんが、 パドルの長さがHPになります。

HPは8で、 被弾するとパドルが短くなります。 ダメージ時に、 後追いゲージのような赤色のもとのパドル長さの残像が残り、 要素が三角形に割れてなくなるような演出を再生します。 短くなると、ボールを打ち返す難易度も上がります。

HPは自然に再生します。 10秒間ダメージを受けずにいると、 1秒間に1のHPを回復します。 このとき、 パドルは1秒かけて線形にの見るアニメーションで徐々に増加します。 当たり判定もアニメーションに従います。 伸びるとき、 丸い白色のパーティクルがパドルの左右から出て、 回復をわかりやすく示唆します。

ダメージ時に少しだけ画面を振動させ、一瞬周りを赤く発行させるエフェクトがあると、ダメージをよりわかりやすく伝えられます。

パドルのHPが0になると、 パドルは完全に破壊されてしまい、 自然再生もストップします。
ただし、 ボールがまだ落下していない場合は、 パドルがなくてもゲームが続行します。

## アイテム

アイテムは、 色付きの図形が0.5秒おきに、 パルスアニメーションを行います。

パルスアニメーションは、 図形を複製して拡大させながら透明にしていくことを指します。

下へゆっくり右回転しながら降下していき、 パドルがそれに触れることで取得できます。

- 赤色の星
    10秒間、 パドルが赤くなってパルスアニメーションを再生します。 これで打ち返したボールは、 `パドルの残り効果時間 + 5秒` の間、 同じように赤くなってパルスアニメーションをします。 このボールはブロックにあたっても反射しなくなり、 貫通していくようになります。

- 黄色の星
    10秒間、 パドルが黄色くなってパルスアニメーションを再生します。 これで打ち返したボールは、 `パドルの残り効果時間 + 5秒` の間、 同じように黄色くなってパルスアニメーションをします。 このボールは通常のボールより大きさが2倍になり、 ボールが線形的な動きでなく物理的なバウンドをするようになります。 (重力は弱め)
    効果が切れるときは、 その時の進行方向を参照して、 滑らかに線形的な動きへトランジションします。

- 緑色の星
    10秒間、 パドルが緑色になってパルスアニメーションを再生します。 これで打ち返したボールは、 `パドルの残り効果時間 + 5秒` の間、 同じように緑色になってパルスアニメーションをします。 このボールは通常のボールより速度が1.5倍になり、 残像を残しながら動くようになります。

- 青色の丸
    これに触れると、 残機が回復します。 残機がフルの場合、 同時に操作するボールの数が増えます。

- ピンク色のハート
    これに触れると、 パドルのHPの自然再生までの残り時間が0になります。

- 紫色の四角形
    これに触れると、 自機よりも下の位置に紫色のパドルが出現します。 このパドルは壁に当たると折り返すというシンプルな動きをし、 ボールを打ち返すこともできます。 このパドルは1回までボールを打ち返すことができ、ボールを打ち返すとパドルは消滅します。 初回は右か左どちらかにランダムに動きます。
    すでに紫色のパドルがある状態で取得すると、 その紫色のパドルの大きさが、紫色のパドル1個分増え、 ボールを打ち返せる回数も1回増えます。 (打ち返せる回数に応じて長さが変化)
    最大で画面いっぱいまで大きくすることができ、 `紫色の四角形の数 + 現在の打ち返せる回数` が最大になる場合、 このアイテムの出現率は0になります。

星型のアイテムはパドルを一定時間強化するもので、 それ以外のアイテムはそれぞれに特別な効果があります。
重複取得した場合、 0.5秒ごとに0.25秒かけてパドルの色が滑らかに変化します。 (緑と赤なら、 緑→赤→緑→赤... となる)

パルスアニメーションするときは、 その時の色をアニメーションします。
